El Pollo Loco

Description:

Beschreibung:

El Pollo Loco is a browser-based platform game developed using HTML, CSS and object-oriented JavaScript. The player controls the character Pepe through various levels, collects resources and battles various enemies, culminating in the final boss. The focus of the project was on implementing interactive game mechanics, animations and a structured object-oriented architecture.

El Pollo Loco ist ein browserbasiertes Jump'n'Run-Spiel, das mit HTML, CSS und objektorientiertem JavaScript entwickelt wurde. Der Spieler steuert die Figur Pepe durch verschiedene Level, sammelt Ressourcen und tritt gegen unterschiedliche Gegner bis hin zum Endboss an. Der Fokus des Projekts lag auf der Umsetzung interaktiver Spielmechaniken, Animationen und einer strukturierten objektorientierten Architektur.

Implementation Details:

Implementierungsdetails:

Object-oriented programming concepts were used in the development to manage characters, enemies, animations and game states in a modular way. Key functions include collision detection, character movement, state management, sound integration and the processing of user interactions via keyboard input. Particular attention was paid to a clean code structure and the separation of individual game components.

Für die Entwicklung wurden objektorientierte Programmierkonzepte eingesetzt, um Spielfiguren, Gegner, Animationen und Spielzustände modular zu verwalten. Zu den zentralen Funktionen gehören Kollisionsabfragen, Charakterbewegungen, Zustandsverwaltung, Soundintegration sowie die Verarbeitung von Benutzerinteraktionen über Tastatureingaben. Besonderes Augenmerk lag auf einer sauberen Code-Struktur und der Trennung einzelner Spielkomponenten.
