Poll-App

Description:

Beschreibung:

Poll App is an interactive web application designed for creating and participating in online surveys. Users can create their own polls with custom questions and answer options, participate in existing surveys, and follow voting results in real time. The application was developed using Angular and TypeScript, with Supabase serving as the backend and PostgreSQL as the relational database. Supabase Realtime enables dynamic updates of voting results without requiring a page reload. Additional features include category-based filtering, highlighting surveys that are ending soon, and a clear visualization of voting results to provide an intuitive user experience. The main focus of this project was developing a reactive frontend architecture, integrating an external database, and handling asynchronous data reliably.

Die Poll App ist eine interaktive Webanwendung zur Erstellung und Durchführung von Online-Umfragen. Nutzer können eigene Umfragen mit individuellen Fragen und Antwortmöglichkeiten erstellen, an bestehenden Abstimmungen teilnehmen und die Ergebnisse in Echtzeit verfolgen. Durch die Integration von Supabase Realtime werden Abstimmungsergebnisse dynamisch aktualisiert, ohne dass die Seite neu geladen werden muss. Zusätzliche Funktionen wie kategoriebasierte Filter, die Anzeige bald endender Umfragen und eine übersichtliche Ergebnisdarstellung sorgen für eine intuitive Benutzererfahrung. Der Schwerpunkt des Projekts lag auf der Entwicklung einer reaktiven Frontend-Architektur, der Integration einer externen Datenbank und der zuverlässigen Verarbeitung asynchroner Daten.

Implementation Details:

Implementierungsdetails:

The application was built with Angular and TypeScript, using Supabase and a relational PostgreSQL database. Supabase Realtime enables dynamic updates of voting results. Row Level Security (RLS) protects database access, while LocalStorage tracks previously submitted votes in the browser.

Die Anwendung wurde mit Angular und TypeScript entwickelt und nutzt Supabase mit einer relationalen PostgreSQL-Datenbank. Supabase Realtime ermöglicht die dynamische Aktualisierung von Abstimmungsergebnissen. Row Level Security (RLS) sichert den Datenbankzugriff ab, während LocalStorage bereits abgegebene Stimmen im Browser nachhält.
