Memory

Description:

Beschreibung:

Memory App is a browser-based card matching game that challenges players to find matching pairs using concentration and memory. At the beginning of each game, cards are placed face down on the board. Players reveal cards one at a time, trying to identify matching pairs. Matching cards remain visible, while unmatched cards are flipped back. The game was developed using TypeScript, HTML, and SCSS, with Vite serving as the development environment and build tool. Special attention was given to a clean user interface, intuitive interactions, and responsive layouts. This project demonstrates fundamental frontend development concepts, including handling user interactions, manipulating HTML elements, and managing different game states without relying on a frontend framework.

Die Memory App ist ein browserbasiertes Kartenspiel, bei dem Spieler durch Konzentration und Merkfähigkeit zusammengehörige Kartenpaare finden müssen. Zu Beginn des Spiels werden die Karten verdeckt auf dem Spielfeld angeordnet. Durch das Aufdecken einzelner Karten versucht der Spieler, passende Paare zu finden. Stimmen zwei Karten überein, bleiben sie aufgedeckt. Andernfalls werden sie wieder umgedreht. Das Spiel wurde mit TypeScript, HTML und SCSS entwickelt. Vite wird als Entwicklungsumgebung und Build-Tool eingesetzt. Das Projekt dient der praktischen Umsetzung grundlegender Konzepte der Frontend-Entwicklung. Dazu gehören die Verarbeitung von Benutzerinteraktionen, die Manipulation von HTML-Elementen und die Verwaltung verschiedener Spielzustände ohne den Einsatz eines Frontend-Frameworks.

Implementation Details:

Implementierungsdetails:

The game was developed with TypeScript, HTML, and SCSS, using Vite as the build tool. The game logic handles card interactions, checks matching pairs, and manages game states. Event handling and DOM manipulation provide a dynamic user interface without a frontend framework.

Das Spiel wurde mit TypeScript, HTML und SCSS entwickelt, mit Vite als Build-Tool. Die Spiellogik verwaltet Karteninteraktionen, überprüft übereinstimmende Paare und steuert den Spielzustand. Event-Handling und DOM-Manipulation ermöglichen eine dynamische Benutzeroberfläche ohne Frontend-Framework.
